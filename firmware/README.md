# ESP32 firmware starter

Install PlatformIO, confirm the exact board, then run `pio run` from this directory. The provisional target is a generic ESP32 development board. No wiring, sensor pins, or power configuration is implied.

This scaffold only prints a startup message. See [system setup](../docs/SYSTEM_SETUP.md) for the upload contract and required persistent-queue behavior. Do not connect sensors before confirming voltage levels, the wiring plan, and power requirements. No firmware has been uploaded to hardware.
